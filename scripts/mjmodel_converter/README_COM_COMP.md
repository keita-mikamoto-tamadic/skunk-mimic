# com_comp — 倒立点実測から重心補正を同定するロジック

[com_comp.py](com_comp.py) が、実測した倒立 pitch から `base_link` と脚リンクの重心補正
(`com_offset`) をどう「割り振って」いるかの導出。結論から言うとヒューリスティックな配分ではなく、
**姿勢ごとに 1 本ずつ立つ方程式を未知数の数だけ集めて解く同定問題**で、割り振りは係数行列の構造
(リンクの向きが姿勢でどう変わるか) が自動的に決める。

使い方・運用は [README.md](README.md) の「倒立点の補正」の節を参照。

---

## 1. 記号

| 記号 | 意味 | mimic_v2_5 の値 |
|---|---|---|
| M | 全質量 | 8.74 kg |
| m_b | base_link の質量 | 2.86 kg |
| 2m_u | 上腿 (upper_link) ×2 の質量 | 3.22 kg |
| hip_i | 姿勢 i の hip 角 | 立位 1.553 / 上げ 0.606 rad |
| θ_i | 姿勢 i の**実測**倒立 pitch | 0.165 / 0.181 rad |
| θ_i^CAD | 同じ姿勢での **CAD モデル**の倒立 pitch | 0.1416 / 0.1521 rad |
| h_i | 姿勢 i での車軸上の重心高さ | 0.102 / 0.181 m |
| dx_b, dx_u | 未知数: base / 上腿 (左右同値) の body 座標 x の重心補正 | 求めるもの |

倒立点の定義: 車軸 (左右ホイール関節原点の中点) から見た全体重心の水平成分 c_x = 0 になる
base pitch。pitch の符号は `ImuData.pitch` (base を +y 軸まわりに回した角) と同じ。

## 2. 倒立点のずれ ↔ 重心の水平ずれ

姿勢 (hip, knee) を固定して base pitch を dθ 回すと、重心は車軸まわりに剛体回転するので
水平に h·dθ 動く。したがってモデルの重心に水平ずれ Δc_x があると、それを打ち消すぶん
倒立 pitch が動く:

```
θ_i^meas − θ_i^CAD = − Δc_x^(i) / h_i          … (1)
```

実測の方が前傾 (θ が大きい) ⇒ 実機の重心はモデルより**後ろ** ⇒ Δc_x < 0、つまり補正は負。

## 3. body 座標のオフセットが水平に効く量

`com_offset` は **body 座標系の x** に足すので、world の水平 (x) に効くのは
「そのリンクが world でどれだけ傾いているか」の余弦ぶんだけ (回転はすべて y 軸まわり):

- base の world 傾き = θ_i           → 寄与 cos(θ_i) · dx_b
- 上腿の world 傾き = θ_i + hip_i    → 寄与 cos(θ_i + hip_i) · dx_u

質量で重み付けして全体重心へ:

```
Δc_x^(i) = (m_b/M)·cos(θ_i)·dx_b + (2m_u/M)·cos(θ_i + hip_i)·dx_u    … (2)
```

## 4. 連立方程式

(1)(2) を合わせると、実測姿勢 i = 1..N について:

```
(m_b/M)·cos(θ_i)·dx_b + (2m_u/M)·cos(θ_i + hip_i)·dx_u = −h_i·(θ_i^meas − θ_i^CAD)
```

**実測姿勢 1 つにつき方程式 1 本**。未知数の数 (補正する body 群の数) を実測数に合わせれば
一意に解ける — これが「同定できる未知数の数 = 実測姿勢の数」の意味。

## 5. mimic_v2_5 の実数値 (2026-08-20)

|  | 立位 (i=1) | 上げ +0.08 m (i=2) |
|---|---|---|
| θ_i + hip_i | 1.72 rad | 0.79 rad |
| **cos(θ_i + hip_i)** | **−0.147** | **+0.706** |
| cos θ_i | 0.988 | 0.984 |
| 右辺 −h_i·(θ_i^meas − θ_i^CAD) | −2.39 mm | −5.23 mm |

係数 (m_b/M = 0.328、2m_u/M = 0.369) を入れると:

```
0.324·dx_b − 0.054·dx_u = −2.39 mm
0.323·dx_b + 0.260·dx_u = −5.23 mm
      ↓
dx_b ≈ −8.9 mm,  dx_u ≈ −9.1 mm
```

com_comp の非線形解 (**base −8.64 mm / upper −9.08 mm**) とほぼ一致する
(差は線形化誤差: h_i や θ^CAD が補正でわずかに動く分)。

## 6. 「割り振り」の正体と分離可能条件

§5 の太字が本質:

- **base の係数 cos θ_i ≈ 0.99 は 2 姿勢でほぼ同じ** — base のずれは姿勢に依らず同じだけ効く
- **上腿の係数 cos(θ_i + hip_i) は −0.147 → +0.706 と符号ごと変わる** — 脚のずれは姿勢で効き方が変わる

なので 1 本目 (立位) はほぼ「dx_b だけ」の式になり、2 本目との差から dx_u が決まる。
「姿勢を変えても共通のずれ → base、姿勢と一緒に変わったずれ → 脚」という直感が、
係数行列の構造そのものになっている。

分離できる条件は行列式 ∝ cos(θ₁+hip₁) − cos(θ₂+hip₂) ≠ 0、すなわち
**実測 2 姿勢で hip 角が十分違うこと**。v2_5 の 2 姿勢は hip が 54° 違うので良条件。
hip 角がほとんど同じ 2 姿勢を与えると行列がランク落ちに近づき、解が大きく振れる
(その場合は base のみに落とすべき)。

## 7. 実装との対応

com_comp.py はこの線形化を**使わず**、(2) の cos の代わりに MuJoCo の順運動学で
厳密な倒立 pitch を計算し (`BalanceModel.balance_pitch`、二分法)、
同じ連立を Gauss-Newton (`fit()`、ヤコビアンは数値微分) で解く。
上の導出はその一次近似で、答えの検算と「なぜ分離できるか」の説明にあたる。

## 8. 限界

- 実測した姿勢では厳密に一致するが、中間・外挿姿勢での一致は「誤差の正体が本当に
  base / 上腿の剛体的な重心ズレである」ことに依存する。膝 PD の重力たわみや IMU 取付角の
  誤差も、この 2 パラメータに射影されて混ざる (立位ではそれで正しく補正される)。
- 検証したければ中間高さで 1 点実測して残差を見る。系統的に残るなら
  `--bodies base_link,upper_link,lower_link` + 3 姿勢に拡張する。
